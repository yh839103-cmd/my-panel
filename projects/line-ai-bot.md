## 這是什麼

一個放在 LINE 裡的 AI 聊天機器人。用手機加好友後就能直接傳訊息問問題，它會用 Google Gemini 回答，還會自己查維基百科和天氣，減少亂掰。

## 功能

- 💬 AI 對話，使用繁體中文與台灣用語
- 🧠 記得最近 10 輪對話，可以接著問
- 🔎 會自己查資料：維基百科（知識）、Open-Meteo（天氣），並註明資料來源
- 📅 知道今天的日期時間
- ⌨️ 指令：「說明」顯示用法、「重新開始」清除記憶
- 🔁 Google 忙線時自動重試，並換用其他免費模型

## 運作方式

```
手機 LINE ⇄ LINE 平台 ──轉交訊息──▶ Render 上的程式（Python + Flask）
                                        ├─▶ 對話記憶
                                        ├─▶ Gemini AI ──需要時──▶ 維基百科／天氣
                                        └─▶ 把答案傳回 LINE
```

## 今天的過程

1. 寫計畫書，確定做「AI 聊天助理」、用 Python
2. 申請 LINE 官方帳號，拿到 Channel secret 和 access token
3. 原本打算用 Claude，但 API 要付費 → **改用 Gemini 免費方案**
4. 程式上傳 GitHub，用 Render 的 Blueprint 一鍵部署
5. 把 Render 網址填回 LINE 的 Webhook，接通
6. 手機加好友測試，一路除錯（見下表）
7. 回答品質不夠好 → 在不花錢的前提下加強：加入日期、更嚴格的回答原則、讓 AI 會查維基百科和天氣

## 遇到的問題與解法

| 問題 | 原因 | 解法 |
|---|---|---|
| 訊息「已讀」但 Bot 不回 | 官方帳號開著「聊天」，訊息跑進真人客服收件匣 | 回應設定：聊天關閉、Webhook 開啟 |
| 收到「本帳號無法個別回覆用戶的訊息」 | LINE 內建的自動回應 | 關閉「自動回應訊息」 |
| Webhook Verify 出現 400 | Render 裡的 Channel secret 填錯 | 從 LINE 重新複製貼上；程式也改成自動去除前後空白 |
| Bot 回「現在忙不過來」 | Gemini 回傳 503，Google 伺服器忙線 | 自動重試，並換用其他免費模型 |
| 回答不太正確 | 免費版不能用 Google 搜尋；AI 不知道今天日期 | 加入日期、回答原則，接上維基百科與天氣查詢 |

## 學到的事

- 訂閱方案（Claude Pro、Google AI Pro 學生方案）**不包含 API**，做 Bot 要用另外計費的 API；Gemini API 有免費方案可以用
- 金鑰就像密碼，只放在 Render 的環境變數，不要放進程式或文件
- 出問題先看 **Render Logs**：有沒有收到 `POST /callback`、錯誤碼是多少，就能判斷問題在哪一段
